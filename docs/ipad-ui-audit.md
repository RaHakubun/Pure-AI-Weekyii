# iPad 界面盘点与阶段性检查

此表记录代码检查及待验证项，不表示已经完成设备上的视觉验收。iPhone 有 5 个顶层标签：过去、今天、未来、扩展、设置。iPad 工作区当前有 11 个路由；其中部分是从同一个 iPhone 模块拆出的独立入口，并非 11 个独立业务模块。

| iPad 路由 | 主要内容 / 子界面 | 本阶段代码检查 | 仍需在 iPad 验证 |
| --- | --- | --- | --- |
| 今天 | 当日状态、任务、启动、后移、习惯详情 | 任务编辑与习惯详情采用表单呈现；修正单列时浮动按钮的布局条件 | 启动流程、后移、不同任务状态、键盘与窗口缩放 |
| 本周 | 周概览、日期详情、任务编辑 | 日期详情限制内容宽度，任务编辑复用表单 | 周布局、日期切换、创建/编辑 |
| 未来 | 周/月、创建周、日期和任务详情 | 创建周及任务编辑采用表单；周详情限制内容宽度；检查器创建任务仅在成功后关闭 | 周/月切换、创建后导航、失败提示、分屏与旋转 |
| 项目 | 项目台账、项目详情、项目/任务编辑 | 项目详情已有自适应列；创建及编辑表单采用系统 form 呈现；检查器编辑只在成功后关闭 | 磁贴布局、拖拽、失败提示、详情及多日期选择 |
| 悬置箱 | 列表、新建/编辑、延期、日期分配 | 新建/编辑和日期分配采用表单呈现；内容约束宽度 | 日期控件、键盘、错误提示及取消操作 |
| 扩展 | 印记、悬置、习惯、项目入口 | 保留原始扩展中心；习惯与印记编辑使用表单，习惯列表及详情约束宽度 | 瓦片缩放、习惯与印记详情、滚动及编辑 |
| 过去 | 历史周/月、周和日期详情 | 原有工作区适配；周/日期详情约束内容宽度 | 日历、历史统计、日期详情和旋转 |
| 洞察 | 摘要、日期选择与检查器 | 已有可读宽度约束 | 数据量、空状态及深浅色 |
| 印记 | 列表、编辑、图片预览 | 编辑采用表单呈现；图片预览保留全屏以便查看原图 | 图片选择、缩放、关闭返回编辑器 |
| 全局搜索 | 搜索结果及关联详情 | 已有可读宽度约束 | 键盘、空状态、结果跳转和检查器 |
| 设置 | 分类、具体设置、任务类型编辑、完整设置 | 分类与具体设置沿用现有页面；任务类型编辑使用表单呈现 | 所有分类、内嵌表单、付费及账户相关流程 |

## 呈现原则与未完成项

- 临时编辑器在 iPad 使用 SwiftUI 系统 `form` 呈现，紧凑窗口仍允许系统适配；iPhone 保持原有呈现。正文的最大宽度不等于限制实际弹窗宽度，两者都要在设备上检查。
- 列表、详情和看板是主要工作区，不强制全部改成弹窗；图片原图预览暂保留全屏。
- 今日启动流程、后移、iCloud 账户选择、购买页及完整设置等呈现尚需逐项验证，不能因为套用统一样式而假定适合所有流程。
- 需要用 Xcode 在多种 iPad 尺寸、横竖屏、分屏/Stage Manager、大字体、键盘弹出及深浅色下运行 UI 测试并查看截图。还需验证 iPhone 无回归。当前环境无法运行 Xcode，本表不是视觉验收结果。
