## 皮肤（`ThemeSkin.cat`）

- 字体：标题与正文都是 `.rounded`，标题 bold。圆角 10 / 14 / 20 / 24。
- 卡片：圆角 22，无描边，暖色柔影；调用方的 accent 只做 9%（深色 10%）的整卡淡染，不画顶部色条（新令牌 `ThemeSurfaceSkin.hidesAccentBar`）。
- 专注面板：`ThemeSurfaceMaterial.gradient`，#EE9558→#D46A32 对角渐变 + 右上 #F6B27C 内光；深色 #3D2C21→#2E2119。面板背后画两只耳朵（右上，`CatEarPairShape`）和一条从右下垂出的尾巴（`CatTailShape`），令牌 `ThemeFeatureSkin.catEars`。次按钮半透明白胶囊；主按钮白胶囊橘字（深色橘底深字）。不再有尾巴刻纹。
- 任务行：`ThemeRowSkin.typeChip`，整行 7% 类型色淡染，类型图标放在 32pt 圆角 11 的 16% 色块里，去掉左侧色条。
- 状态徽章：`ThemeBadgeKind.softPill`，14% 状态色胶囊 + 14pt 猫剪影 + 文字。
- 分区标题：图标 + 粗体标题 + 橘色计数胶囊（`ThemeCountKind.capsule`）+ 圆点虚线（`ruleDotted`）+ 末端实心爪印。
- 选中态（分段指示、主按钮、选中日）：`gildedFill` 为橘色上浅下深渐变，白字 / 深色 #2A1A10。
- 设置图标：`ThemeIconSkin.tintsFill`，14% 行色底 + 行色图标，能映射的换猫剪影。主题色块：橘色渐变上一张奶油色猫脸。
- 杀时间滑块：10pt 橘色渐变轨道；拇指是白色圆 + 2pt 橘圈 + 粉色肉球。
- 字标：圆体 heavy 橘色渐变，"W" 上立两只耳朵。
- 今日背景：浅色是从右上窗口斜照下来的三道暖光；深色是几颗微闪的星和右上角的橘色灯光。去掉了 v1 的地毯线、角落蜷猫和全屏爪印底纹（`ThemeBackdrop.pawTrail` 已删除）。
- 状态插画：扁平房间（窗、太阳 / 弯月与星、光束、坐垫），坐垫上蜷睡一只橘猫，身体呼吸，"z z z" 飘起；318×104 设计空间，等比铺满。
