# Weekyii 1.2.1 (2) — 扩展页与项目结项更新

- Date: 2026-11-27 23:45 (Asia/Shanghai)。
- Branch: `online-chatgpt-develop`，release commit `cdc2fa0`（版本号）；功能提交 `ac6dd09`（预报切换）、`7fa2ba8`（项目结项）。
- 上一版：1.2.1 (1)，11-20 归档、11-23 上架。
- 版本变更：`CURRENT_PROJECT_VERSION 1 → 2`（App 与 Widget 的 Debug / Release / Beta 共 6 处）；`MARKETING_VERSION` 保持 1.2.1；测试 Bundle 保持 1.0 / 5。

## Scope

三组用户可感知改动，全部在扩展 / 未来周界面，不涉及数据模型：

1. **项目结项不再要求全部任务完成**（`7fa2ba8`）
   - `ExtensionsViewModel.updateStatus` 移除 `isAllCompleted` 门槛，连同已无用的 `WeekyiiError.projectHasOpenTasks` 一起删除。
   - 结项只改 `project.status`，遗留任务不摘不删，继续挂在项目上；项目转只读由既有 status 检查保证。
   - 有遗留任务时先确认（「结项后项目转为只读 / 还有 N 项任务未完成…」），全部完成仍是一键绿卡。
2. **项目台账列出逾期任务**（`7fa2ba8`）
   - `ProjectDetailComposer.projectTaskLedgerSections` 不再过滤逾期任务；`ProjectTaskLedgerSection` 新增 `overdueTaskIDs`，`expiredCount` 语义变为「其中逾期几项」。
   - 任务行新增橙色「逾期」胶囊；结项后隐藏「下一步」卡，指标与周汇总的「待办」改为「遗留」。
   - 修正随之引入的重复计数：`tasks` 含逾期后，日标题不再 `+ expiredCount`，`ProjectDetailWeek.openCount` 与日按钮的 `open` 排除 `overdueTaskIDs`。
3. **未来周预报的「重点 / 轨迹」切换缩小**（`ac6dd09`）
   - 原生分段控件（每段 75×32）换成自绘胶囊（每段 44×19），保留 `pendingWeekOutlookPicker_<weekId>` 与 `.isSelected` 语义。
4. **扩展首页删除「给生活，多一点空间」标题行、tab 图标换为 `circle.grid.2x2`**（`c89723f`，已在 1.2.1 (1) 之后合入本分支）。

## 数据安全

- SwiftData / migration impact: none。没有新增或修改 `@Model` 字段、关系、唯一性。
- CloudKit / entitlement impact: none。没有新实体、新字段、新容器；`project.status` 是既有字段。
- 语义变化提醒：结项后项目内仍可能存在未完成任务（`zone != .complete`）。它们会继续出现在「当下 / 过去 / 未来」的按天视图中，参与逾期统计。这是有意设计：项目是档案，任务仍然可查、可继续完成。
